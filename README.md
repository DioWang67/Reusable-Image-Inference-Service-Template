# IrisForge – Reusable Image Inference Service Template

IrisForge is a production-oriented, reusable image inference service template built in Python 3.10+. It is designed to serve various computer vision models (e.g., classification, detection, OCR) with minimal changes, focusing on engineering quality and extensibility.

## Features

*   **FastAPI Application**: A modern, high-performance web framework for building APIs.
*   **Model Abstraction**: A generic `InferenceEngine` interface that decouples the API logic from the model backend, with an initial implementation for ONNX Runtime.
*   **Manifest-based Model Loading**: Define and version models using simple YAML manifests.
*   **Preprocessing and Postprocessing**: A pluggable pipeline for pre- and post-processing, configured on a per-model basis.
*   **Observability**: Structured JSON logging and Prometheus-compatible metrics for monitoring.
*   **Containerized**: A Dockerfile is included for easy deployment.

## Getting Started

### Prerequisites

*   Docker

### Running the Service with Docker

1.  **Build the Docker image:**

    ```bash
    docker build -t iris-forge .
    ```

2.  **Run the Docker container:**

    ```bash
    docker run -p 8000:8000 iris-forge
    ```

The service will be available at `http://localhost:8000`.

## API Documentation

The API documentation is automatically generated by FastAPI and is available at `http://localhost:8000/docs` when the service is running.

### Endpoints

*   `GET /healthz`: Health check endpoint.
*   `POST /v1/infer/{model_name}/{model_version}`: Perform inference on a single image.
*   `POST /v1/infer:batch/{model_name}/{model_version}`: Perform inference on a batch of images.

## Model Manifests

Models are defined in YAML files located in the `manifests` directory. Each manifest contains the following information:

*   `model_name`: The name of the model.
*   `version`: The version of the model.
*   `backend`: The model backend to use (e.g., `onnx`).
*   `artifact_path`: The path to the model artifact, relative to the `models` directory.
*   `input_preprocessing`: A list of preprocessing steps to apply to the input image.
*   `output_type`: The type of output from the model (e.g., `classification`).

## Local Development

### Prerequisites

*   Python 3.10+
*   pip

### Setup

1.  **Install the dependencies:**

    ```bash
    pip install -r requirements.txt
    pip install -r test-requirements.txt
    ```

2.  **Run the service:**

    ```bash
    uvicorn src.iris_forge.main:app --reload
    ```

### Running Tests

To run the tests, use `pytest`:

```bash
pytest
```
